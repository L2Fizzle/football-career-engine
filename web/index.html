⚽ Football Career Engine ⚽

A Python-based football career simulator. Experience a realistic, event-driven progression of a professional footballer from debut through retirement.

Engine Architecture

Event-Driven Match Engine

Matches are generated through simulated events (shots, key passes, dribbles) weighed dynamically against player attributes, team strength, and opponent defense.

Object-Oriented Player Model

A dedicated Player class centralizes state management, making attribute progression, transfer valuation, and lifetime career tracking clean and maintainable.

Dynamic League Tables

Simulates full Premier League seasons with realistic promotion and relegation logic. Team data is handled via external I/O files for easy balancing and scaling.

Modular Architecture

Built for the long term. Separation of concerns is built-in, with match simulation, league management, and application flow split into distinct Python modules.
